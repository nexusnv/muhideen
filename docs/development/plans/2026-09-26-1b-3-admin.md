> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the mobile-width admin surface — first-boot wizard, settings tunables, and safe QR fast-connect — as thin `fetch()` clients over the existing settings/auth APIs.

**Architecture:** Server-rendered prefilled pages (usable first paint) with vanilla JS handling submit flows; no new JSON endpoints (HTML routes carry no JSON contract, per 1B precedent). QR PNG is generated server-side into a data URI (LAN URL only, never secrets). First-boot gating (setup open iff no admin exists, 409 after) is the one-time setup mechanism — no token endpoint (out of scope; flagged below).

**Tech Stack:** Jinja2, vanilla CSS/JS, segno (pure-Python QR, license verified in Task 1), pytest e2e via ASGI TestClient.

**Locked interpretation (flag):** PRD FR-6.3/§5.4 say "one-time setup token". No token mechanism exists in the contract, and adding issuance/validation endpoints is a security-surface change beyond 1B-3. This plan implements the wizard against the landed first-boot gate (open setup ⇔ no admin; single-use via 409) and shows the note "Setup closes after the first admin is created." If a real token is required, it needs its own slice + ADR.

```python
"""Server-side QR PNG as a data URI (FR-6.3 fast-connect).

Pure function: text in, ``data:image/png;base64,...`` out. Callers pass
the LAN URL only — never credentials. segno is pinned for zero runtime
dependencies; the matrix parameters are fixed so output is deterministic.
"""

from __future__ import annotations

import base64
import io

import segno


def qr_data_uri(text: str) -> str:
    """Encode ``text`` as a PNG QR data URI (deterministic)."""
    buffer = io.BytesIO()
    segno.make(text).save(buffer, kind="png", scale=6, border=2)
    return "data:image/png;base64," + base64.b64encode(buffer.getvalue()).decode(
        "ascii"
    )
```

def login_context() -> dict[str, object]:
    """Context for the login page (no data needed)."""
    return {"lang": "bm"}

    """Context for the first-boot wizard (no data needed)."""
    return {"lang": "bm"}

    *, settings: SettingsDTO, qr_data_uri: str, fallback_url: str
) -> dict[str, object]:
    """Prefilled settings page plus QR block (LAN URL only, never secrets)."""
    return {
        "lang": "bm",
        "current": settings,
        "qr_data_uri": qr_data_uri,
        "fallback_url": fallback_url,
    }
